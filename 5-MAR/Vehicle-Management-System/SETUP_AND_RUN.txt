TROUBLESHOOTING GUIDE
================================================================================

PROBLEM 1: "javac: command not found" or "Java is not recognized"
SOLUTION:
- Java is not installed or not in PATH
- Download Java from java.com or oracle.com
- Install Java Development Kit (JDK), not just JRE
- Restart your terminal/command prompt after installation
- Verify: Type "java -version" should show version number

PROBLEM 2: "cannot find symbol" during compilation
SOLUTION:
- All Java files must be in SAME directory
- Check spelling of class names matches in import statements
- Delete any accidental copies of files
- Try compiling one file first: javac Vehicle.java

PROBLEM 3: "class X is public, should be declared in a file named X.java"
SOLUTION:
- Each public class must be in its own file with same name
- Vehicle.java must contain ONLY Vehicle interface
- Car.java must contain ONLY Car class
- File names are case-sensitive on Mac/Linux

PROBLEM 4: "NoClassDefFoundError" when running
SOLUTION:
- Make sure you compiled ALL files first: javac *.java
- Delete all .class files and recompile: del *.class (Windows) or rm *.class (Mac/Linux)
- Check that class name is spelled correctly: java VehicleRentalSystem

PROBLEM 5: "Exception in thread" during execution
SOLUTION:
- Enter valid inputs according to the prompts
- For doors: enter number ≥ 2
- For fuel type: enter "petrol", "diesel", or "electric"
- For wheels: enter 2 or 3
- For motorcycle type: enter "sport", "cruiser", or "off-road"
- For capacity: enter positive number like 5.5
- For transmission: enter "manual" or "automatic"
